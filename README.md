# 🚀 Rocket Manager — Frontend
 
Interface web do sistema de gestão de projetos Rocket Manager, desenvolvida com Angular 17.
 
## 🛠️ Tecnologias
 
- Angular 17
- TypeScript
- SCSS
- ngx-toastr
## ▶️ Como rodar
 
```bash
npm install
ng serve
```
 
Acesse `http://localhost:4200`
